# Copy / i18n

Abbitomator’s dashboard is **English-first**. There is no catalog runtime.

## Rules

- Do not hardcode Portuguese (or any other locale) into Astro pages.
- Client-facing weekly/monthly PDFs are English (Stuart Mitchell).
- Abby’s notes are free text and may be any language — do not translate them.
- Brand mark letters (`AB`) stay in markup.

## Status labels

Live → `pill pill--ok` (“Live”). Off → default `pill` (“Off”).
